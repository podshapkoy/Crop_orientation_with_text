# Crop orientation with text

Решение определяет, находится ли OCR-кроп в правильной ориентации (`0°`) или перевёрнут на `180°`, и создаёт `submission.csv` с вероятностью `p_180`.

## Идея решения

Используется небольшая готовая модель PaddleOCR `PP-LCNet_x1_0_textline_ori`. Она специально обучена различать два класса:

- `0_degree`;
- `180_degree`.

Для каждого изображения модель делает два предсказания: для оригинала и для копии, повёрнутой на 180°. Они объединяются по формуле:

```text
p_tta = (p180(original) + 1 - p180(rotated)) / 2
```
если изображение повернуть на 180°, вероятность также должна инвертироваться.

Обучающая выборка
---
Обучающая выборка была составлена с помощью скрипта `data_generating/generate_data.py`. 
Внутри него генерируются 20 000 синтетических картинок с текстом на русском и английском языках. 
Сами надписи пишутся разными шрифтами — прямо, под углом или изогнуто дугой. 
Текст накладывается на сложные фоны: случайные вырезки из реальных фото, текстуры блокнотной бумаги или градиенты. 
Затем скрипт добавляет искажения перспективы, размытие, цифровой шум и артефакты сильного JPEG-сжатия.

И после перенесены данные на [Яндекс.диск](https://disk.yandex.ru/d/HyHIzF7JIi9DIA)

---


Все синтетические изображения изначально находятся в ориентации `0°`. Поэтому:

- оригинал имеет метку `0`;
- его программный поворот на 180° имеет метку `1`.

На этих данных подбирается один параметр `temperature`, который улучшает качество вероятностей для метрики Brier Score. 
Сама нейросеть дополнительно не обучается.

## Запуск

Перейдите в папку проекта:

```bash
cd project
```

Соберите Docker image:

```bash
docker compose build
```

Скачайте данные:

```bash
docker compose run --rm ocr-orientation \
  python -m data_generating.download_data
```

Подберите temperature на синтетических данных:

```bash
docker compose run --rm ocr-orientation python calibrate.py
```

Создайте предсказания:

```bash
docker compose run --rm ocr-orientation python predict.py
```

Результат будет сохранён в:

```text
project/output/submission.csv
```

## Калибровка

1. Из 20 000 исходных изображений выбираются 2 000
2. Выбранные изображения делятся на `development`, `calibration` и `validation`
3. Модель получает вероятность для каждого оригинала и его поворота
4. На `calibration` подбирается один `temperature` по Brier Score
5. Значение используется только в том случае, если оно улучшает Brier Score на `development`
6. Метрики печатаются на всех трёх частях, а результат сохраняется в `checkpoints/calibration.json`


Сеть нужна только для установки библиотек и скачивания датасета. Веса модели уже находятся в `project/models/`.
