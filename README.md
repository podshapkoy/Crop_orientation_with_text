# Определение ориентации текста на изображениях

Данное решение определяет ориентацию кропа с текстом, найденного OCR-моделью. Задача — классифицировать, находится ли текст в правильной ориентации (`0°`) или перевёрнут вверх ногами (`180°`), и выдать вероятность `p_180` в формате `submission.csv`.

## Архитектура пайплайна и подход

Пайплайн состоит из трех ключевых этапов: легковесная модель $\rightarrow$ Test-Time Augmentation (TTA) $\rightarrow$ Калибровка вероятностей.

### 1. Базовая модель
В качестве бейзлайна используется легковесная сверточная нейросеть `PP-LCNet_x1_0_textline_ori` из библиотеки PaddleOCR. 
Она специально обучена на задачу детекции ориентации текстовых строк. 

### 2. Test-Time Augmentation (TTA)
Для устойчивости предсказаний к шумам и сложным шрифтам, применяется TTA.
Для каждого входного изображения модель делает два прохода:
- Предсказание для оригинала $\rightarrow$ $p_{orig}$
- Предсказание для копии, программно повёрнутой на 180° $\rightarrow$ $p_{rot}$

Если текст перевернут, вероятности должны инвертироваться. Итоговая вероятность рассчитывается как среднее:
```text
p_tta = 0.5 * (p_orig + (1.0 - p_rot))
```

### 3. Калибровка вероятностей
Основная метрика соревнования — **1 - Brier Score**, поэтому выходы модели должны быть честными вероятностями. 
Выходы TTA проходят через калибровку (Temperature Scaling или Isotonic Regression). 
Параметры калибратора подбираются на сгенерированных синтетических данных.

## Данные

Так как обучающая выборка не предоставлялась, был написан собственный генератор данных (`data_generating/generate_data.py`).

**Особенности генерации:**
* **Доменная адаптация:** Тексты генерируются с учетом специфики классифайдов (ценники со скидками, бренды одежды, электроника, бытовые товары)
* **Сложные фоны:** Текст накладывается на случайные вырезки из реальных фото (COCO dataset), градиенты или текстуры бумаги
* **Имитация мобильных фото:** Чтобы модель не переобучилась, применяются сильные деградации, имитирующие плохие камеры:
  * Motion Blur (смаз в движении)
  * Perspective Transform (фото под углом)
  * Gaussian Noise (шум матрицы)
  * Сильное JPEG-сжатие

Сгенерированный датасет загружен на [Яндекс.Диск](https://disk.yandex.ru/d/HyHIzF7JIi9DIA) для удобства скачивания.

## Установка и запуск

Для полной изоляции и воспроизводимости решение упаковано в Docker. 
Веса модели (`project/models/`) уже лежат в репозитории, интернет нужен только для скачивания датасетов. 
Зафиксированы все `random_seed`
Перейдите в папку проекта:

```bash
cd project
```

Соберите Docker image:

```bash
docker compose build
```

Скачайте данные:

```bash
docker compose run --rm ocr-orientation \
  python -m data_generating.download_data
```

Подберите temperature на синтетических данных:

```bash
docker compose run --rm ocr-orientation python calibrate.py
```

Создайте предсказания:

```bash
docker compose run --rm ocr-orientation python predict.py
```

Результат будет сохранён в:

```text
project/output/submission.csv
```
