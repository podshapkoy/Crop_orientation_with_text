# PP-LCNet_x1_0_textline_ori

Официальная open-source модель PaddleOCR для классификации ориентации текстовой строки на `0_degree` и `180_degree`.

- Источник: [PaddleOCR model repository](https://huggingface.co/PaddlePaddle/PP-LCNet_x1_0_textline_ori)
- Проект: [PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR)
- Лицензия: Apache-2.0
- Заявленная авторами accuracy: 98.85%

Inference-файлы хранятся в проекте, поэтому во время `calibrate.py` и `predict.py` модель не скачивается и внешний inference API не вызывается.
